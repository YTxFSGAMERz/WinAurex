## 2. Disclaimer of System Modifications

WinAurex interacts deeply with the Windows operating system kernel, service manager, registry hives, and DISM image servicing components.

> [!CAUTION]
> **Important Safety Notice**:
> Applying aggressive system tweaks, disabling background Windows services, or debloating system packages carries inherent risk. While WinAurex includes transactional rollback capabilities and automated System Restore checkpoint creation, **you are ultimately responsible for backing up your data before executing system-level modifications**.

### User Responsibilities
1. **Always Create a System Restore Point**: Prior to executing the live debloat scripts or applying new registry tweaks.
2. **Review Tweak Presets**: Understand which features are disabled in specific profiles (e.g., Extreme Gaming disables Xbox services and Bluetooth discovery).
3. **Hardware Compatibility**: Ensure your device drivers and BIOS meet minimum stability criteria before applying latency-sensitive kernel scheduling tweaks.
