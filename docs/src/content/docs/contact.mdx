## 🔒 Security Vulnerability Reporting

If you identify a security issue, privilege escalation bug, or potential vulnerability in WinAurex:

1. **Do not create a public issue**.
2. Email full reproduction steps to `farhanahmad3162@gmail.com` with the subject line: `[SECURITY] WinAurex Vulnerability Report`.
3. You will receive an acknowledgment within 24 hours, followed by a prioritized patch release.
