## 💡 About the WinAurex Live Web Studio

The **WinAurex Web Studio** is the web companion to the **WinAurex C# WPF Desktop Framework**. It allows system administrators, gamers, developers, and deployment engineers to craft tailored Windows configurations directly in the browser with zero installation required.

### 🌟 Key Capabilities
- **Unattended Windows 11 Answer Files (`autounattend.xml`)**: Automate full OS installations, bypass TPM 2.0, Secure Boot, RAM checks, and automatically provision local offline administrator accounts.
- **Transactional PowerShell Scripts (`.ps1`)**: Generate scripts that create system restore checkpoints before executing atomic modifications to services, DISM packages, and system profiles.
- **Precision Registry Optimizations (`.reg`)**: Direct MMCSS GPU priority tuning, DPC latency optimization, and telemetry eradication.
- **Rollback Safety**: Backed by WinAurex's event-sourced JSON manifest architecture ensuring all changes can be reversed with a single click.
